## Knowledge base

A persistent, cross-project wiki lives at `~/wiki/wiki/` (search: `qmd query "<topic>" -c wiki`,
conventions: `~/wiki/schema.md`). When a question may already be answered there, start at
`~/wiki/wiki/index.md`. Before finishing, file findings back: update the page, `index.md`, and append
a row to `log.md`.

One wiki for every project on this machine — never a wiki per repo.
